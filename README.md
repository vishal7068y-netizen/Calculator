# Calculator Web App

This is a simple calculator web application created as part of my Web Development Internship task.

The calculator is built using HTML, CSS, and JavaScript with a simple and responsive student-friendly interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus operation
- Decimal calculations
- Clear (C) button
- Delete (DEL) button
- Input validation
- Division by zero handling
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

While building this project, I practiced JavaScript functions, DOM manipulation, conditional statements, error handling, and basic arithmetic operations.

I also learned how HTML, CSS, and JavaScript work together to create an interactive web application.
